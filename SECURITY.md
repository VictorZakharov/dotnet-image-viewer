# Security policy

## Supported version

Security fixes are made against the latest commit on `main`. Older snapshots
and locally modified builds are not maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** action on the repository's Security tab. If private
vulnerability reporting is unavailable, contact the maintainer through the
GitHub profile without including exploit details in a public message.

Include affected versions, reproduction steps, impact, and any proposed
mitigation. Reports will be acknowledged as soon as practical; timelines vary
with severity and the complexity of a safe fix.
